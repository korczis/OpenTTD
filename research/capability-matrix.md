# Capability matrix: what every capability runs on today

RESEARCH-ONLY. One row per capability of this fork: who owns it, the code that does it (cited as
`path:line:Symbol`), what it reads from a live game, what happens when that input or its engine is
missing, where its numbers come from, the tests that run it, and whether it has run end to end,
with the run that proves it. Read from master on 2026-11-22. Where another document already holds
a part of this, the row links to it rather than repeating it: the stage table of the agent loop
([`agent-loop.md`](agent-loop.md)), the authority matrix of Battlebrain
([`battlebrain/README.md`](battlebrain/README.md#authority-matrix)) and the phase status of the MCP
server ([`prismatic-mcp/05-implementation-plan.md`](prismatic-mcp/05-implementation-plan.md)).

## How to read it

- **Code path.** Every `path:line:Symbol` names a line of master that holds `Symbol`.
  `tools/knowledge/refs check --pathspec research/capability-matrix.md --strict-lines` fails on a
  citation whose file is gone, whose line is past the file's end, or whose line no longer holds
  its symbol, and on a bare `path:line` it cannot verify. It runs in `tools/surfaces/surfaces check`
  (the commit hook, `tools/gate.sh change`, CI), declared in [`surfaces.toml`](../surfaces.toml).
  When code above a citation moves, `tools/surfaces/surfaces sync` rewrites the line to where the
  symbol is now when that is one line (`--fix-lines`: the symbol's only line, or its only
  declaring line); a symbol that is gone, or now on several lines, fails until a person re-reads
  the code and edits the row.
- **End to end.** The taxonomy of [`README.md`](README.md): **PASS** names a committed record of a
  live run, or a command run for this page, that shows the capability working; **PARTIAL** names
  what ran (a live run of part of it, a replay of a real capture, or a run reported only in prose)
  and what did not; **NOT RUN** means no live run is recorded, and names the issue that owns it.
  Unit tests are in their own column and never make a row PASS.
- **Label.** The weakest kind of evidence in the row. **OBSERVED**: read in the cited code at this
  commit, and every status taken from a committed record opened for this page. **DERIVED**: some of
  the row is taken from another document's table or prose without re-running it. **INFERRED**: some
  of the row is concluded from reading code, with no run and no record behind it.
